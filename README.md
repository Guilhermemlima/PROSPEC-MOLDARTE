# Moldarte3D CRM

CRM e envio de mensagens de prospecção pelo WhatsApp para a Moldarte3D (Guarapuava).

- `index.html`: o sistema (abra no navegador)
- `leads-data.js`: 750 leads de Guarapuava (Google Maps)
- `mensagens.js`: mensagens por segmento (aumente `VERSAO` ao editar para atualizar no navegador)

Os status, anotações e valores ficam salvos no navegador (localStorage). Use **Backup / Importar** para baixar um backup.
